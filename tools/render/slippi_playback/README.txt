Slippi's playback Dolphin goes here (not included).
1. Install Slippi Launcher (https://slippi.gg/downloads), open it, watch any replay once.
2. Copy the CONTENTS of %APPDATA%\Slippi Launcher\playback\ into this folder
   (so tools\render\slippi_playback\Slippi Dolphin.exe exists).
3. Create an empty file portable.txt in this folder.
4. Settings (frame + audio dumping, no async shaders...): guides\01 Install and setup.html, step 3.
replay_render.py uses only this private copy; the Launcher's own copy is never touched.
