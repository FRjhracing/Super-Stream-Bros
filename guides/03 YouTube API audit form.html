YouTube API quota extension: answers

Current state (2026-11-17): the default quota is enough (separate limit of 100 uploads/day; an upload costs ~50 query units), so a whole tournament uploads in one run. Only apply to lift the Private-only lock on unaudited projects: ask for the default quota and lead with the Public/Unlisted request. What the quota page looks like.

The form's wording changes now and then, so match each answer to the closest question. "Copy" puts the answer on the clipboard.

Before you start

  1. Search YouTube API Services Audit and Quota Extension Form (it's a Google Form linked from the YouTube API "Quota and compliance audits" page). Sign in as the channel owner.
  2. Google Cloud console → project picker: note the project name and project ID. The project number is also the start of your OAuth client ID.
  3. Optional but helpful: a screenshot of a terminal upload run and of the tournament playlist in YouTube Studio. They often ask how the app looks or works.

Which APIs / scopes
YouTube Data API v3. OAuth scope: https://www.googleapis.com/auth/youtube Methods: videos.insert (resumable upload), playlists.list, playlists.insert, playlistItems.insert, channels.list (mine=true, to confirm the signed-in channel).

What the app does

Describe your use case
I run a weekly local esports tournament (Super Smash Bros. Melee, about 20 players). After each event I cut the stream recording and the game replays into one video per match plus one full video per game station, typically about 25 videos per week, all footage we recorded ourselves at our own event. A personal command-line script (Python, run only by me on my own PC) uploads these videos to my own YouTube channel with the YouTube Data API: it uploads each file with a resumable upload, sets the title and description that my tool generates (players, characters, round, timestamps), and adds each video to that week's tournament playlist. The app has no other users, no web interface and no access to anyone else's channel or data. It only writes to my channel; it does not read, collect or store YouTube user data beyond the video IDs it just uploaded (kept in a local file so a run can resume).
Why do you need more quota?
With the default 10,000 units per day, videos.insert (1,600 units) allows about 6 uploads per day, so each week's ~25 videos takes 4-5 days to upload and the backlog overlaps the next tournament. I would like to upload one tournament's videos in a single run the day after the event.
Quota requested (units per day)
50,000
How did you calculate it?
Per weekly tournament: about 26 videos.insert x 1,600 = 41,600 units, plus 26 playlistItems.insert x 50 = 1,300, plus a few playlists.list / playlists.insert / channels.list calls (under 200). Total about 43,100 units on the upload day; 50,000 leaves margin for a re-upload or a larger event. Usage is one day per week; the other days are near zero.
How often / when is the API used?
Once a week, the day after the tournament, in one batch run started manually.

Data & compliance

How do you store / protect data and credentials?
OAuth uses Google's installed-app flow with PKCE and a loopback redirect. The client secret and refresh token are stored only on my PC in my Windows user profile (not in any shared folder, code repository or cloud storage). No YouTube API data is shared with third parties. The only data kept is the list of video IDs/URLs the script uploaded, in a local file, so an interrupted run can continue. Access can be revoked at any time from my Google account's security settings.
Do you display / share API data with others?
No. The videos themselves are published on my channel by me in YouTube Studio; the app does not display API data anywhere.

Also asking for Public/Unlisted uploads (lift the "Private" lock)?
Yes. Videos uploaded by this unverified project are locked to Private. I would like the audit to also cover uploading as Unlisted/Public so I don't need to change each video's visibility by hand.

After sending: Google replies by email, sometimes with follow-up questions. Approval raises the project's quota in the Cloud console (APIs & Services → YouTube Data API v3 → Quotas); no code change is needed.
