Super Stream Bros

The tool set behind the PROTOCOL* weekly Smash tournaments: bracket and overlay docks for OBS, Slippi replay collection, automatic VOD cutting (stream + off-stream sets rendered from replays), YouTube uploads and Lucky Stats set pages. Plain Python and local web pages; an AI agent is optional.

★ beta = used at our events but not thoroughly tested yet. Found a bug or something unclear? Open an issue on GitHub (FRjhracing).

* PROTOCOL is the weekly series these tools were built for. Its names, links, stream name, setup names and layout appear in the docs and examples as real-world samples: swap in your own.

The week in six steps

  1. NightDock + OBS run the bracket and stream; every set is put on a setup in the dock.
  2. HandoffRecording + dock log to the SSD (Stream PC); Ultimate TO copies theirs.
  3. Replaysslippi_uploader.py: plug in each flash drive.
  4. Videosssb_autopilot.py N --upload★ beta, or plan / review / render by hand.
  5. Lucky StatsUpload the zips, paste the event link, sync descriptions.
  6. PublishCheck and publish in YouTube Studio; clean up after 2 weeks.

The Stream PC side

The Melee dock runs the bracket from three browser pages and writes the overlay files; a generator turns layout.json into an OBS scene collection, so stream and VODs share one layout. Seasonal themes (round names + panel art) are picked in the dock. Walkthrough: Stream PC guide.

Shown: the real OBS 33 import of the generated scene with the sample panel's Halloween theme and a made-up bracket.

Generic sample overlay (included)

The package ships blank sample art (panel, pictures, logo) and falls back to a standard Windows font, so renders work before you add your own look. The layout map shows which file feeds each spot, and layout.json moves everything for a different stream layout.

Not included: third-party software, the Melee ISO, PROTOCOL's own overlay art and font. The setup guide links each download.
